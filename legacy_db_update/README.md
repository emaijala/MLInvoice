# Database update scripts for legacy VLLasku

These scripts are required to bring a VLLasku 1.0 to 1.4 database up to the level that MLInvoice's automatic database migration can handle.

E.g. for VLLasku 1.0 you'll need to run all the scripts sequentially, whereas for version 1.4 you'll only need `update_database_1.4_to_1.5.sql`.
